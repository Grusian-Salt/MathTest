# Тест на математическое мышление

Тест по трём темам (алгебра, геометрия, тригонометрия) с таблицей лидеров на базе **Google Таблиц**.

## Запуск

Вопросы загружаются из `questions.json` через `fetch`, поэтому страницу нужно открывать через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Настройка таблицы лидеров (Google Таблицы)

Таблица лидеров состоит из двух частей: чтение результатов (CSV из Google Таблицы) и запись новых результатов (веб-приложение Google Apps Script).

### 1. Создайте таблицу

1. Создайте новую таблицу на [docs.google.com/spreadsheets](https://docs.google.com/spreadsheets).
2. Переименуйте первый лист в `Лидерборд`.
3. В первой строке укажите заголовки:
   `Фамилия и имя | Группа | Результат | Всего | Проценты | Дата`

### 2. Откройте доступ на чтение

Кнопка **«Настройки доступа»** → **«Все, у кого есть ссылка»** → **Просмотр**.

Скопируйте **ID таблицы** из адресной строки — это часть между `/d/` и `/edit`:

```
https://docs.google.com/spreadsheets/d/1AbCdEfGhIjKlMnOpQrStUvWxYz/edit
                                                ^^^^^^^^^^^^^^^^^^^^
                                                это и есть ID
```

### 3. Создайте веб-приложение для записи

1. В таблице откройте меню **Расширения → Apps Script**.
2. Вставьте в редактор этот код:

```javascript
function doPost(e) {
  const sheet = SpreadsheetApp.openById('СЮДА_ID_ТАБЛИЦЫ').getSheetByName('Лидерборд');
  const data = JSON.parse(e.postData.contents);
  sheet.appendRow([
    data.name,
    data.group,
    data.score,
    data.total,
    data.percent,
    new Date().toLocaleString('ru-RU')
  ]);
  return ContentService.createTextOutput(JSON.stringify({ status: 'ok' }))
    .setMimeType(ContentService.MimeType.JSON);
}
```

3. Нажмите **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - «Выполнять от имени»: **Я**;
   - «Кто имеет доступ»: **Все**;
   - Нажмите **Развернуть** и подтвердите разрешения.
4. Скопируйте **URL веб-приложения** (выглядит как `https://script.google.com/macros/s/.../exec`).

### 4. Впишите настройки в script.js

В начале файла [`script.js`](script.js) укажите:

```javascript
const SHEET_ID = '1AbCdEfGhIjKlMnOpQrStUvWxYz';              // ID таблицы из шага 2
const SHEET_NAME = 'Лидерборд';                               // имя листа
const APPS_SCRIPT_URL = 'https://script.google.com/macros/s/.../exec'; // URL из шага 3
```

## Как это работает

- После завершения теста результат отправляется `POST`-запросом в веб-приложение Apps Script, которое добавляет строку в таблицу.
- При открытии «Таблицы лидеров» сайт читает таблицу как CSV через Google Visualization API и сортирует строки по проценту верных ответов.
- Новые результаты появляются в таблице в течение нескольких секунд (из-за кэша Google) — при необходимости обновите страницу.
